## Interface contract

Add a focused skating-query helper, or equally small functions under the existing owner.
Its obstruction input contains previous/next world riding transforms and immutable proxy shape transforms.
Its output is empty for no hit, otherwise `{collider, fraction, at, normal}` in world coordinates.
`fraction` is finite in [0,1]; select the earliest qualifying obstruction across all proxies.
The collider must be a currently valid unbroken non-traffic CrashProp from this route.
Queries do not arm, pay, spawn limbs, or advance clocks; `main.gd` owns the single resulting activation/bail.
Handle starting overlaps separately because `cast_motion()` ignores already overlapping query shapes.
Do not infer a contact from the broad-phase radius; filter a true overlap/sweep by its rider-contact policy.
Support placement returns the simulation root's grounded world height and resets with route/retry placement.
R05 presentation interpolation may smooth the display but must not change the authoritative riding transform.
