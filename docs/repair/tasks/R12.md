## Integration contract

Retain all three existing routes, hats, poses, injury thresholds, and one crashbreaker charge.
The default first-launch line still demonstrates a physically caused cascade.
Alternative lanes/poses/charge/early versus late breaker can change actual outcomes.
Never award fallback points or force a wreck to meet a gameplay test score.
Every payout has a traceable accepted injury/contact event and capped object identity.
A single object and each finite anatomical budget cannot pay twice via replay/retry artifacts.
An unarmed background vehicle collision cannot fund the player.

Pending session bests remain separate and do not display as secured.
Replay cannot change score, committed records, live fuses, forces, or causal edge ledger.
The supported result exits, route changes, and quit paths stop all simulation ownership cleanly.
