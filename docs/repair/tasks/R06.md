## Timeline contract and rationale

Create one immutable attempt tape keyed by stable actor ID, never incidental array index.
Physics actor samples carry actual elapsed simulation time from R05, sorted monotonically.
Capture a complete initial crash state at bail and an exact final settlement state from R09.
Preserve an irregular final interval instead of treating it as another full .05-second period.
Retain accumulator remainder for capture scheduling; interpolation uses stored timestamps.
Stable IDs and recorded presence permit playback of actors cleaned up before settlement.
Keep bounded replay resources until tape discard or rebuild visual proxies from actor metadata.
Do not retain an unbounded scene history or create a second physical simulation.
Live camera sampling has per-render ownership because R05/R07 move the camera on render time.
Record camera transform, FOV and sample simulation time after the final safe render camera update.
Record initial/final camera boundaries even when no render sample occurred at that physics instant.
Use the latest completed render sample at each boundary and record its own time/age explicitly.
Do not pair a stale camera with new actor state and label both as sampled simultaneously.
Camera samples interpolate on their own sorted timestamps against the same playback clock.
Use bail as tape simulation origin0. Normalize source camera times to that origin and preserve
pre-bail age; never relabel a stale source as simultaneous with an actor boundary. Store increasing
capture sequence; at equal timestamps the latest sequence wins before bracketing distinct times.
Outside the camera sample range hold earliest/latest views, including an older final render source.
Actor time clamps to [0,duration]. A zero-duration tape disables replay; no interpolation divides by0.
The default view reproduces the recorded camera; C cycles recorded → chase → side → overhead.
Alternate views use replayed actor focus and R07 safety, never the frozen final live torso.
This keeps the promised camera choice useful without adding forces, driver logic or payout.

## Data and ownership interfaces

Tape header: attempt ID, route/pose identity, duration, capture cadence and stable actor catalog.
Actor catalog: ID, visual resource/kind, spawn transform and presentation reconstruction metadata.
Include immutable camera-query shape geometry/local transforms for dynamic props in the catalog.
Actor samples: simulation time, ID→transform, presence/visibility and discrete visual states.
Record limb severity, prop damage, traffic wheel/lamp/driver display and fuse visual state.
Record receipts and event visibility with explicit simulation timestamps and stable event IDs.
Camera samples: simulation time, camera transform, FOV and explicit boundary/sample provenance.
Avoid storing mutable live dictionaries by reference; deep-copy/finalize the tape at settlement.
Immutable means playback cannot write to tape entries or authoritative live state.
Replay owns presentation proxies or equivalent isolated visual state, with physics disabled.
Alternate cameras query route geometry plus query-only prop geometry at replay time, excluding frozen
live dynamic RIDs. A bounded static query proxy set uses numeric collision_layer 0x10
(Godot inspector layer 5), collision_mask 0. Existing live masks 3 and 7 ignore that bit;
replay queries combine static bit 1 and proxy bit 0x10 as numeric collision mask 0x11.
Never attach contact/driver/payout callbacks to query proxies; synchronize them before camera solving.
Dispose query proxies on every exit. Test a prop with disjoint early/final transforms: only the
visible replay-time hull can obstruct an alternate view, not its invisible frozen final collider.
It must not call hit/ignite/shatter/activate, driver integration, impulse or bank APIs.
Never use live `apply_snapshot` to modify cause/armed/fuse/paid fields during playback.
Use a dedicated visual snapshot adapter for proxies; keep authoritative settlement state intact.
Isolate mutable material/morph/wheel state as well as dictionaries. Test live shader/damage values
during proxy playback; sharing mutable resources cannot satisfy presentation isolation.
Hide live meshes/effects while proxies are visible without disabling needed result state ownership.
On entry preserve final live presentation visibility and camera state for exact restoration.
On completion, retry, route exit or disposal, remove proxies and restore the agreed final state.
Pause/help stop the playback clock using R05's pause baseline; closing returns to the same sample.
R11 consumes replay entry/exit lifecycle hooks for music-only playback; do not synthesize live claims/sounds.
R10 continues to own funding/save UI, so playback never changes durable/session funding status.
