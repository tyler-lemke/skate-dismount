# R01 implementation evidence

Implemented startup selection, reusable pre-ready fixtures, and a strict bounded process runner on Godot 4.7.2.stable.official.ed1daf0bf. The preserved contamination reproduction remains in builds/repair_audit; the old shared records file is no longer selected by test mode.

Startup precedence: exactly one absolute `--records-path=` overrides a pre-ready injected path; otherwise test/capture/self-check allocate a unique project-local directory. Normal launch uses user://records.json. Invalid overrides quit before any records read. Inaccessible explicit parents are not created or replaced with a user profile. `startup_records_read_path` observes the actual first-read destination.

Cold startup: builds/repair_audit/R01_targeted/startup/output.log.result.json reports STARTUP: 279 checks, 0 failures across 30 actual cold engine cases, including simultaneous distinct [11,22,33] and [91,82,73] fixtures, scoped poison, order/precedence, v1/v2, invalid overrides, missing/blocker parents, and unique defaults. INPUTS:39 checks,0 failures at builds/repair_audit/R01_targeted/inputs-v2/output.log.result.json, including independent child-process persisted-hat reload. The preceding failing input log is preserved at inputs/output.log; its two fixture defects were missing child log isolation and strict int-vs-decoded-float equality, not relaxed expected values.

Runner controls: 21 Python unittest cases pass at builds/runner_controls/20261005T021139.671533Z-3b02d417/result.json. Cases exercise actual subprocess CLI failures, missing/wrong/duplicate/malformed/zero markers, nonzero exit after success, exact certificate diagnostic plus later error, timeout with an ignoring descendant, and leader exit leaving a child. Timeout cleanup uses fixture-only liveness checks, with process-group terminate/kill.

Public entry: `GODOT_BIN=/opt/homebrew/bin/godot ./tools/test.sh [--timeout-seconds 10..600] [--registry path]`. Helper: `python3 tools/run_bounded.py --timeout-seconds 180 --log ABSOLUTE_LOG --expected-summary NAME -- argv...`. Default import and suite deadlines are 180 seconds. Each actual run records argv/hash, engine version, source digest, exit, time, fixture path and parsed completion markers in builds/test_runs/<run-id>/<suite>/result.json.

TestFixtures.create_game(root) writes/selects the known fixture before add_child triggers _ready. `prepare(game, fixture, write_fixture)` permits custom scenarios. Cold child observations use suite-local output and engine logs. Route, playability and traffic JSON reports live beside the selected records fixture. render_snapshot.gd also writes scene_*.json there; Blender render_validation.py accepts its existing SCENE_FILE override for that artifact.
